# BERKAS_3B_02_Dataset_KabutAsap
# Dataset Anotasi Deteksi Objek Citra Berasap
**Repositori Tugas Mata Kuliah Sistem Berkas**

Repositori ini berisi kumpulan dataset citra kabut asap yang telah dilengkapi dengan anotasi *bounding box* berformat YOLO untuk keperluan pelatihan model deteksi objek. Proyek ini dikerjakan secara berkelompok untuk memenuhi target minimum 100 citra teranotasi.

**Daftar Kelas Objek (Classes):**
1. Kendaraan
2. Gedung
3. Manusia

## Struktur Direktori
- `/gambar` : Berisi kumpulan citra kabut asap (.jpg / .png).
- `/labels` : Berisi file anotasi koordinat bounding box format YOLO (.txt).
